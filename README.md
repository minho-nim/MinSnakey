# 꼬물 레이스 v0.5

직접 그린 머리·몸통·꼬리로 CPU 3마리와 경주하고, 완주 결과를 친구에게 도전 링크로 보내는 웹게임.

- 플레이: https://minho-nim.github.io/snake-race/
- GitHub: https://github.com/minho-nim/snake-race
- 기존 소유자 확인용 사이트: https://kkumul-race-minho.lmh000603.chatgpt.site

## 실행

Node.js 22 이상 (검증: 24.19.0).

```bash
npm ci
npm run dev       # http://localhost:5173
npm run check     # 타입 검사 + 물리/데이터 테스트 + 빌드
npm run test:e2e  # Chromium에서 실제 PC/모바일 UI 검증
```

Chromium 기본 경로는 `/usr/bin/chromium`. 다른 머신에서는 `CHROMIUM_PATH`를 지정한다. `dist/play.html`에는 실행에 필요한 CSS·JS가 전부 포함된다. 로컬 파일과 웹 주소는 저장 공간이 서로 다르다. GitHub main 업데이트 시 `.github/workflows/pages.yml`로 자동 배포한다.

## 구현

- 머리·몸통·꼬리 단계별 자유 그리기, 색·굵기·부분 지우개·되돌리기·연결점 이동
- 원래 그린 경로를 따르는 25개 몸통 관절, 원본 선 스키닝과 크기 비율 유지
- 길이·무게·크기에 따른 가속력·최고속도·지구력·유연성·안정성·접지력 표시
- 차량 동역학의 출력/질량/접지 한계, 속도 제곱에 비례하는 공기·물 저항, 경사·부력 반영
- 100m 평지, 언덕 달리기, 물웅덩이 달리기, 점프 장애물 달리기
- 자동·수동 조작, 모바일 좌우 추진 버튼, A/D·방향키
- 카운트다운, 고정 배율 카메라, 실제 거리 순위, 일시정지·재개·재시작·종료
- 기본 3배, 추가 2배·4배·8배 빨리감기 (실제 3/6/12/24배)와 남은 경기 실제 계산을 통한 결과보기
- 코스/규칙/조작별 최고 기록, 이전 그림·기록 보존
- 완주 후 친구 도전 링크 생성·복사, 새 브라우저에서 도전장 확인, 실제 상대 기록 재생

## 검증

- 물리·형태·기록·도전 데이터 검증 32개
- Chromium PC/모바일 검증 11개
- 같은 출력/형상에서 질량 증가에 따른 가속 감소, 면적 증가와 속도 제곱에 비례하는 유체 저항, 세 코스 완주와 기록 차이 확인
- 30/120fps 및 빨리감기 결과 일치, 일시정지·재시작·즉시 결과 계산 확인
- 자동·수동 친구 경기의 링크 전송 후 원본 기록 재현, 새 브라우저 도전 흐름 확인
- 터치 그리기, 부분 지우개, 연결점 편집, 실제 완주·새로고침 후 저장 확인

실제 iOS/Android 하드웨어, Safari, 장시간 메모리 프로파일과 다양한 사용자를 대상으로 한 밸런스 검증은 남아 있다.

## 한계와 다음 단계

- 그림에서 추정하는 질량·출력·저항계수는 게임 규칙이며 실제 재질을 측정한 값이 아니다. CFD·난류·완전한 강체 엔진은 아니다.
- 현재 코스는 경사·얕은 물·점프 장애물을 지원한다. 실제 회전 조작은 아직 없다.
- 친구 배틀은 기록 도전이다. 실시간 동시 대전·공용 서버 순위·자동 결과 통지는 없다.
- 링크가 너무 길어지는 복잡한 그림은 공유할 수 없다. 선을 줄여 다시 생성해야 한다.
- 그림은 가장 긴 몸통 펜 경로를 골격으로 사용한다. 면의 중앙선 자동 추출은 추후 과제다.
- 그림·기록은 브라우저에 저장한다. JSON 내보내기·기기 동기화는 추후 기능이다.
- AI Office 작업 전달 연동과 전용 저장 클라우드 환경은 미설정이다. 저장소는 AI Office와 독립적으로 유지한다.

## v0.5 변경

- 최대 42%·36%의 두 언덕, 경사에 맞춘 몸통 표현, 오르막/내리막 HUD와 미리보기.
- 장애물 3개, 중력에 따른 점프, 공중 이중 점프 방지와 충돌 감속. 자동 모드는 자동 점프, 수동은 버튼·Space/W/↑, 일시정지는 P 키.
- 큰 능력치 숫자와 굵은 막대, 그리기 중 주요 능력치 실시간 표시.
- 공유 도전 입장에서 저장한 내 뱀 선택 또는 새 뱀 그리기를 명확히 구분. 새로 그린 뱀도 같은 상대·코스로 연결.
- 24배 진행과 수동 입력·점프·입력 배속을 기록 재생에서 재현. 바뀐 코스는 새 규칙으로 비교하고 이전 기록은 보존.
