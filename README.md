# 꼬물 레이스 v0.6.1

직접 그린 머리·몸통·꼬리로 CPU 3마리와 경주하고, 완주 결과를 친구에게 도전 링크로 보내는 웹게임.

- 플레이: https://minho-nim.github.io/snake-race/
- GitHub: https://github.com/minho-nim/snake-race
- 공유 미리보기 서버 / 게임 미러: https://kkumul-race-minho.lmh000603.chatgpt.site

## 실행

Node.js 22 이상 (검증: 24.19.0).

```bash
npm ci
npm run dev       # http://localhost:5173
npm run check     # 타입 검사 + 물리/데이터 테스트 + 빌드
npm run test:e2e  # Chromium에서 실제 PC/모바일 UI 검증
```

Chromium 기본 경로는 `/usr/bin/chromium`. 다른 머신에서는 `CHROMIUM_PATH`를 지정한다. `dist/play.html`에는 실행에 필요한 CSS·JS가 전부 포함된다. 로컬 파일과 웹 주소는 저장 공간이 서로 다르다. GitHub main 업데이트 시 `.github/workflows/pages.yml`로 자동 배포한다.

## 한계와 다음 단계

- 그림에서 추정하는 질량·출력·저항계수는 게임 규칙이며 실제 재질을 측정한 값이 아니다. CFD·난류·완전한 강체 엔진은 아니다.
- 현재 코스는 경사·얕은 물·점프 장애물을 지원한다. 실제 회전 조작은 아직 없다.
- 친구 배틀은 기록 도전이다. 실시간 동시 대전·공용 서버 순위·자동 결과 통지는 없다.
- 링크가 너무 길어지는 복잡한 그림은 공유할 수 없다. 선을 줄여 다시 생성해야 한다.
- 그림은 가장 긴 몸통 펜 경로를 골격으로 사용한다. 면의 중앙선 자동 추출은 추후 과제다.
- 그림·기록은 브라우저에 저장한다. JSON 내보내기·기기 동기화는 추후 기능이다.
- AI Office 작업 전달 연동과 전용 저장 클라우드 환경은 미설정이다. 저장소는 AI Office와 독립적으로 유지한다.

## v0.6.1 변경

- CPU 세 마리를 다른 손그림으로 구성: 삼각 주둥이·뿔·각진 몸통의 귤빛 뿔룡이, 돌출 눈·둥근 얼굴·굵고 짧은 몸통의 보라 통통이, 뾰족한 얼굴·길고 가는 몸통·갈라진 꼬리의 민트 리본이.
- 준비 화면과 경기에서 같은 그림을 사용하며 실제 그림에서 능력치를 계산한다. 통통한 몸은 장애물에 닿을 수 있고 모든 CPU가 같은 물리·점프·충돌 규칙을 따른다.
- 머리는 몸통 끝의 한 관절 각도를 그대로 따라 꺾이지 않도록 넓은 목 방향을 기준으로 완만하게 회전한다. 실제 연결점과 원본 선을 유지하며 준비 화면·경기·공유 이미지에 같은 변환을 사용한다.
- 기본 초록 샘플과 사용자가 저장한 그림, 기존 공유 상대 원본은 유지한다.

## v0.6 변경

- 맨 위 기본 선택인 종합경기: 0~20m 출발, 20~42m 언덕, 50~58m·64~72m 물, 80m·92m 점프. 구간별 실제 힘·에너지·충돌을 누적해 완주 시간으로 우승자를 정하며 특정 체형에 승리 보정을 주지 않는다.
- 평지·언덕·물·장애물은 특성을 비교하는 개별 종목. 장애물 충돌은 55% 즉시 감속과 0.7초 넘어짐/추진 감소를 적용한다. 물은 잠긴 면적·물 밀도·속도 제곱에 따른 저항을 적용한다.


- 카카오톡 등에 붙여 넣을 도전 링크에 내 뱀 원본과 기록을 그린 1200×630 PNG, 장난스러운 도전 문구 4종을 제공한다.
- GitHub Pages는 게임을 계속 제공한다. 공개 Sites Worker의 `/c?d=…`는 OG 메타데이터를 응답하고 브라우저는 원래 GitHub 게임의 도전장으로 이동한다. `/og.png?d=…`는 해당 그림으로 PNG를 만든다.
- 계정·DB·API 키 없이 압축한 그림/기록을 URL로 전달한다. 공유한 그림과 기록은 링크를 아는 누구나 볼 수 있다.
- 무게 범위 0.45~7.5kg, 출력 24~52W, 길이에 따른 에너지 저장량 차이를 확대했다. 큰 체격의 공기·물 저항과 무게에 따른 가속 차이가 실제 경기 결과에 반영된다. 경기 중 추진 체력 막대도 표시한다.
- 자동 오르막 저단 추진을 적용하되 출력과 접지 한계를 유지한다. 새 규칙은 morphology-v3. 그림·기존 기록은 유지하며 예전 도전장은 새로 만들어야 한다.

### 공유 서버 개발·배포

`npm run build`는 게임과 `share-server/dist/server/index.js` ESM Worker를 모두 만든다. `npm run dev:share`와 `npm run dev`를 함께 실행하면 Vite가 공유 경로를 8787번 서버로 전달한다. E2E는 두 서버를 직접 시작한다. Worker에는 단일 파일 게임과 글자 비트맵을 포함하며 외부 폰트/API 호출을 하지 않는다. PNG 글자 비트맵 재생성은 Chromium과 Noto Sans CJK KR이 있는 환경에서 `node scripts/make-share-assets.mjs`로 수행한다.

Sites 배포는 기존 프로젝트 `appgprj_6aea95ba4ec08191b8a0db6e608c1897`의 소스 저장소에 빌드 결과를 커밋·푸시하고 `.openai/hosting.json`(해당 project_id, static 설정 없음)과 `dist/server/index.js`를 묶어 저장·배포한다. 이 Worker 배포는 GitHub Actions의 Pages 배포와 별개다. 게임 공유 데이터 형식이나 규칙이 바뀌면 Worker도 함께 배포해야 한다.

크롤러 방식의 HTML 메타데이터와 PNG 응답, 브라우저에서 공유 링크 진입·도전까지 검증했다. 실제 카카오톡 앱의 썸네일 표시는 별도 확인이 필요하며 앱의 캐시·긴 URL 제한에 영향을 받을 수 있다. 완주 후 새 도전 링크를 생성해 공유한다.
