# 부위별 물리·조립 규칙 v5

MinSnakey는 그림에서 추정한 체형 계수에 힘·출력·중력·유체 저항의 기본 식을 적용하는 게임이다. 그림으로 실제 재질이나 부피를 측정하는 CFD·생체역학 시뮬레이션은 아니다. 원본 선과 연결점은 보존하며 모든 선수에게 같은 120Hz 고정 간격 엔진을 적용한다.

## 조립과 자동 체급

- 몸통의 이어진 획을 하나의 골격으로 잇는다. 닫힌 윤곽은 양쪽 경로 사이의 중심선을 사용해 머리와 꼬리가 같은 이음새에 몰리지 않게 한다.
- 머리는 몸통 오른쪽, 꼬리는 왼쪽 끝에 연결한다. 머리·꼬리는 처음 그린 연결점을 유지하며 장식을 추가해도 바꾸지 않는다. 연결점 자동 맞춤·수동 이동·되돌리기를 지원한다.
- 정지 상태에서 머리·꼬리의 추가 회전은 0이다. 움직일 때만 원래 골격에 대한 상대 각도를 제한해 적용한다. 그리기 조립 미리보기는 정지 상태로 표시한다.
- 전체 선을 비율 그대로 최대 가로 6.4m·세로 1.6m 체급으로 맞추며 작은 그림은 가능한 범위에서 최대 1.35배 확대한다. 원본 파일과 저장 그림은 수정하지 않는다.
- 연결점에 닿지 않은 선은 반투명하게 표시하고 조립·출전을 막는다. 닫힌 윤곽 안의 눈·입과 머리 가까운 작은 눈 장식은 허용한다. 인정된 얼굴 장식은 질량·크기·저항·자동 체급 계산에서 제외한다.

## 부위별 역할

| 부위 | 실제 계산 | 그리기 참고 |
|---|---|---|
| 머리 | 별도 질량·정면 면적·항력계수, 앞쪽 무게중심, 충돌 충격 | 작고 길쭉하면 저항 감소. 커지면 무게와 앞쪽 쏠림 증가. |
| 몸통 | 추진 출력·에너지 저장, 파동 전달 효율·접지, 몸통 저항 | 길고 적당히 굵으면 출력·지구력 증가. 과한 굵기·굴곡은 무게·저항·전달 손실 증가. |
| 꼬리 | 별도 질량·항력, 물을 미는 면적, 뒤쪽 질량 분포와 착지 감쇠 | 넓으면 물 추진과 저항이 함께 증가. 긴 꼬리는 흔들림을 줄이지만 무게가 증가. |

무게는 보정된 선 면적과 부품 면적에서 추정한 전체 0.45~7.5kg를 세 부위에 분배한다. 부위 질량의 합은 전체 질량과 같다. 무게중심은 각 질량과 위치의 가중 평균이며 관성은 부위 위치·크기·몸통 길이로 추정한다. 얼굴 장식은 제외한다.

출력은 몸통 길이·굵기에서 24~52W, 에너지 저장량은 1000~9500J 범위로 추정한다. 너무 부드럽거나 뻣뻣한 몸의 전달 효율은 낮아진다. 추진 에너지 하한 55%는 완주 안정성을 위한 게임 제한이다.

## 힘과 물 접촉

- 공기·물 저항: `F = 0.5 × 밀도 × Cd × 면적 × 속도²`.
- 머리·몸통·꼬리별 정면 면적과 노출 비율을 적용한다. 노출 비율은 앞 부위의 가림을 근사한 게임 계수다.
- 물은 수심, 점프 높이와 자세로 각 부위의 실제 잠긴 단면을 계산한다. 물 밖에 뜬 부위는 수중 저항·부력을 받지 않는다.
- 꼬리의 파동이 물을 밀면 추진에 기여한다. 지면 추진과 꼬리 추진은 같은 모터 출력 안에서 나누며 별도 에너지를 생성하지 않는다.
- 접지 한계는 `μN`, 지면 저항은 `CrrN`, 경사 저항은 `mg sinθ`, 가속도는 순힘을 전체 질량으로 나눠 계산한다.
- 공기 밀도 1.225kg/m³, 물 밀도 1000kg/m³, 중력 9.81m/s²를 사용한다.

## 점프·충돌·착지

점프는 제한된 에너지를 수직 운동에너지로 바꿔 시작하고 중력에 따라 착지한다. 공중에서는 지면 추진을 받지 않는다. 자동 점프는 몸 전체 길이와 공중 감속까지 고려해 시점을 정한다. 너무 무겁거나 긴 체형은 뒷부분이 장애물에 걸릴 수 있다.

장애물과 머리·몸통·꼬리의 가로 범위가 겹치는지, 해당 부위 높이가 충분한지 구분한다. 처음 걸린 부위에 따라 속도 손실·충격 방향·회복 시간이 달라진다. 장애물 하나당 한 번만 충격을 적용하며 실제 걸린 부위를 기록한다. 앞쪽 충돌과 꼬리 걸림은 반대 방향의 회전 충격을 만든다.

질량 분포는 이륙 반응과 관성에 영향을 준다. 착지 때 기울수록 속도 손실이 생기며 꼬리의 균형 계수는 착지 손실과 흔들림을 줄인다. 각도는 ±0.35rad로 제한하고 지상 복원·감쇠를 적용해 계속 회전하지 않게 한다. 자유 낙하 중 무게중심 자체가 새로운 회전력을 만드는 방식은 사용하지 않는다.

## 코스·기록·공유

기본 종합경기는 출발 평지, 20~42m 언덕, 50~58m·64~72m 물, 80m·92m 점프 구간을 묶는다. 평지·언덕·물·장애물 개별 종목도 같은 엔진을 사용한다. 기본 진행 3배와 추가 2/4/8배는 계산을 빠짐없이 수행하며 카운트다운은 실제 시간이다.

NPC는 경기 준비 단계에서 평지와 얕은 물의 예상 주행 능력에 가까운 실제 체형 후보를 고른다. 실제 경기 중 거리·속도 보정이나 승리 지정은 없다. 친구의 원본 그림·기록·수동 입력은 변경하지 않는다.

결과의 출발 20m 시간, 물 접촉 평균 속도, 부위별 충돌과 착지 횟수는 실제 시뮬레이션에서 수집한다. 가상의 손해 시간이나 입력은 만들지 않는다.

공유는 원본 그림·코스·입력·규칙 버전을 압축한 링크와 상대 기록의 재현을 사용한다. 규칙 v5 이전 도전장은 새 링크가 필요하다. 기존 그림과 이전 기록은 유지하고 같은 규칙·코스·조작의 기록끼리 비교한다. 실시간 동시 대전·공용 순위 서버·자동 결과 통지는 없다.
