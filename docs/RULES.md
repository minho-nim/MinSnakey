# 체형·차량 동역학·유체 저항 규칙 v2

이 게임은 손그림으로 추정한 계수에 차량 동역학의 기본 힘 방정식을 적용한다. 그림만으로 실제 재질·밀도·출력을 알아낼 수 없으므로 이들 계수의 대응은 게임 밸런스 규칙이다. 유체의 압력장·난류를 푸는 CFD 또는 정밀 생체역학 시뮬레이션은 아니다.

## 1. 체형과 능력치

- 길이: 몸통의 가장 긴 펜 경로를 따라 측정. 안전 범위 1.5~6.5m.
- 무게: 전체 선 길이·펜 두께와 머리·꼬리의 추정 면적을 반영. 0.65~4.5kg.
- 크기: 몸통 굵기와 머리·몸통의 체격을 반영. 길이와 구분한 정면 크기다.
- 여섯 능력치: 가속력, 평지 최고속도, 지구력, 유연성, 안정성, 접지력. 점수는 0~100으로 표시하고 시뮬레이션에는 원래 SI 단위 값을 사용한다.

같은 형상과 출력에서 무게가 늘면 가속력이 줄고, 지면 저항·경사 저항은 증가한다. 접지 가능한 최대 힘도 늘지만 가속 계산에서 다시 질량으로 나누므로 무겁다고 더 빠른 것은 아니다. 큰 정면 면적은 저항을 높인다. 긴 몸은 직진 안정성과 추진 출력/에너지 저장 여유가 생기지만 길이만으로 최고속도를 결정하지 않는다. 머리만 과도하게 크게 그리면 무게·정면 면적·균형에 부담이 생긴다.

## 2. 힘 계산 (SI 단위)

- 공기 저항: F = 0.5 × 공기 밀도 × Cd × 정면 면적 × 속도²
- 수중 저항: 같은 식에 물 밀도와 잠긴 단면적을 적용
- 추진력: min(저속 추진력 한계, 출력 / 속도) × 파동 결합 효율 × 입력 × 남은 에너지
- 접지 한계: μ × 지면 수직항력
- 지면 저항: Crr × 수직항력
- 경사 저항: 질량 × g × sin(경사각)
- 가속도: (추진력 − 공기저항 − 수중저항 − 지면저항 − 경사저항) / 질량
- 부력: 물 밀도 × g × 잠긴 부피. 얕은 물에서는 지면 수직항력을 일부 줄인다.

상수: 공기 밀도 1.225kg/m³, 물 밀도 1000kg/m³, g=9.81m/s². 동작은 120Hz 고정 간격이다. 평지 최고속도는 추진 출력과 저항에 필요한 출력이 같아지는 속도를 수치적으로 구한다. 원래 펜 경로의 골격과 파동을 유지하며 모든 선수에게 같은 식을 적용한다.

추진 출력은 체형으로 22~44W 범위, 에너지 저장량은 1200~2500J 범위로 추정한다. Cd·μ·Crr, 유연성과 안정성 역시 그림으로 정하는 게임용 근사다. 에너지 감소 하한과 최고속도 상한은 완주 안정성을 위한 게임 제한이다. 회전 반경·기어 변속·타이어 변형·유체 난류는 구현 범위에 포함하지 않는다.

## 3. 코스

| 코스 | 거리 | 규칙 |
|---|---:|---|
| 100m 달리기 | 100m | 평지, 공기/지면 저항 |
| 언덕 달리기 | 100m | 16~38m, 52~72m에 최대 ±42%, ±36%인 두 언덕. 오르막은 중력을 이겨야 하고 내리막에서는 중력이 가속을 돕는다. |
| 물웅덩이 달리기 | 100m | 28~34m, 62~68m의 깊이 3.5cm 얕은 물. 수중 저항·부력·젖은 지면 접지 변화를 적용한다. |

| 점프 장애물 달리기 | 100m | 25m·48m·73m에 높이 0.45m·0.65m·0.55m 장애물. 자동 선수는 자동 점프, 수동은 버튼·Space/W/↑. |

거리와 순위는 실제 진행 거리로 계산한다. 렌더링의 언덕 높이는 가독성을 위해 축약하지만 물리 계산은 실제 경사 값을 사용한다. 카메라 배율은 경기 중 고정하고 창 크기가 바뀔 때만 갱신한다.

## 4. 친구 기록 도전

완주 결과에서 ‘친구에게 도전장 보내기’를 누르면 그림 원본, 코스, 조작 방식, 규칙 버전, 완주 기록, 수동 모드의 실제 수락된 조작을 압축한 링크를 만든다. 친구는 링크를 열어 자기 뱀을 선택하거나 새로 그리고 같은 조건에서 대결한다. 친구의 경기 재생이 CPU 한 자리를 대체한다.

도전 링크를 열 때 현재 엔진으로 기록을 재현해 확인한다. 다른 규칙 버전·손상 데이터·재현되지 않는 시간은 거절한다. 수동 상대를 자동 모드로 바꾸거나 가짜 입력을 생성하지 않는다. 최대 링크 길이와 압축 해제 크기를 제한한다.

실시간 동시 접속·공용 순위 서버·보낸 사람에게 결과 자동 통지는 없다. 다시 도전장을 보내 결과를 공유할 수 있다. 서버 검증이 없는 개인 간 기록 도전이며 치팅 방지 대회 시스템은 아니다. Github Pages 주소에서는 로그인 없이 접근할 수 있다.

## 5. 기존 데이터

저장된 그림과 이전 기록은 유지한다. 새 규칙 기록은 규칙 버전·코스·자동/수동을 구분해 비교한다. 이전 규칙의 평지 최고 기록은 경기 준비 화면에 따로 표시한다. 저장소 키는 그대로 유지하며 데이터를 초기화하지 않는다.

## 6. 점프·진행 속도·구버전 호환

점프는 제한된 에너지를 수직 운동에너지로 바꿔 v=√(2E/m)으로 시작하고 g에 따라 착지한다. 공중에서는 지면 접지 추진을 받지 않는다. 재점프는 착지 후에만 가능하다. 장애물과 실제 몸통·꼬리의 가로 범위가 겹칠 때 높이가 부족하면 장애물마다 한 번 감속·에너지 손실을 적용한다. 자동 점프 판단은 모두 같은 앞쪽 거리 기준을 사용한다.

기본 진행은 3배. 추가 배속 1/2/4/8은 실제 3/6/12/24배이며 카운트다운은 실제 시간이다. 고정 120Hz 계산을 빠짐없이 수행한다. 사람의 수동 입력 리듬은 받아들인 배속과 함께 기록하며 다른 재생 속도에서도 원래 결과를 재현한다.

평지·물 코스의 v1 도전장은 호환을 유지한다. 달라진 언덕 코스의 v1 기록 도전장은 새로운 링크가 필요하다. 이전 규칙 기록은 삭제하지 않고 이전 최고 기록으로 표시한다.
